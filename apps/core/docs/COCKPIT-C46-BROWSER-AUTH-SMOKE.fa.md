# C46 — آزمایش صفحه ورود در مرورگر واقعی
تاریخ: 2026-10-09

**نتیجه: ۷/۷ سناریوی Chrome موفق؛ Production همچنان NO-GO.**

## فایل‌های آزمایشی
- `apps/core/tests/c46-browser/index.html`
- `apps/core/tests/c46-browser/main.tsx`
- `apps/core/tests/c46-browser/smoke.mjs`

این ورودی کاملاً جدا از `src/main.tsx` است و از همان کامپوننت واقعی `App` و آداپتر C36 با client ساختگی استفاده می‌کند. هیچ Supabase واقعی یا BFF تجاری فراخوانی نمی‌شود.

## آنچه آزمایش شد
1. بدون نشست: فرم ورود نمایش داده می‌شود و دکمه تا اعتبار ورودی غیرفعال است.
2. رمز ساختگی غلط: پیام خطای فارسی امن.
3. موبایل ۴۲۰ پیکسل: بدون اسکرول افقی.
4. ورود ساختگی موفق: مسیر داده مدیر بسته می‌ماند؛ بدون Mock یا درخواست کسب‌وکار.
5. خروج: بازگشت به فرم Login.
6. تزریق عمدی Runtime آزمایشی: در مسیر مدیر رد می‌شود.
7. هیچ خطای JavaScript در مرورگر رخ نداده است.

صفحه در ۱۳۶۵×۷۶۸ و ۴۲۰×۸۰۰ دیده و تصاویر آزمایشی فقط در پوشه Temp ساخته شدند. مشکل قفل فایل موقت Chrome در اجرای اول اصلاح شد؛ تکرار آزمون با `EXIT=0` موفق بود.

## تکرار امن
از مسیر `apps/core`:
```powershell
npx.cmd vite --configLoader native --host 127.0.0.1 --port 5176 --strictPort
node.exe tests/c46-browser/smoke.mjs http://127.0.0.1:5176/
```
سرور محلی را بعد از تست متوقف کنید. هیچ Push، Merge، Deploy یا اتصال واقعی انجام نشده است.

## محدودیت
این آزمون HTTPS یا JWT و Supabase واقعی را بررسی نکرده؛ آن بخش جداگانه در آزمایش HTTPS مصنوعی BFF ارزیابی شده است. تست C46 جانشین بازبینی امنیت میزبان نیست.
