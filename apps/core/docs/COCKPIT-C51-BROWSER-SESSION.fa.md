# C51 — آزمون نشست مرورگر و خروج امن

تاریخ: 2026-10-12

- آداپتر ورود مرورگر نشست دارای زمان انقضای گذشته، غیرعددی، یا نامعتبر را نپذیرد.
- رویداد خروج از SDK اعتبار نشست را فوراً لغو کند؛ رویداد دیررس مثبت اجازه ورود مجدد ندهد.
- فقط ورود صریح تازه پس از خروج می‌تواند نشست جدید بسازد؛ BFF و سرور همچنان مرجع اصلی مجوز هستند.
- تست های Node از کلاینت ساختگی استفاده می‌کنند. پوشش Chrome موجود C46 برای ورود، خروج، موبایل و نبود داده Mock در مسیر مدیر مستقل اجرا می‌شود.
- Production و اتصال Supabase واقعی: NO-GO؛ هیچ Fetch/Push/Merge/Deploy یا مهاجرتی در این مرحله نیست.
