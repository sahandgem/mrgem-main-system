# C52 — قطع ارتباط و حالت خطای امن مرکز فرمان

- 2026-10-12؛ فقط Core / محیط آزمایشی، بدون هرگونه اتصال بیرونی.
- شکست دریافت اولیه: هیچ نمای ساختگی یا داده جعلی نمایش داده نمی‌شود؛ پیام فارسی و دکمه تلاش مجدد.
- شکست پس از موفقیت قبلی: نمای قبلی صرفاً برای زمینه تاریخی حفظ شده و بنر واضح «داده جاری نیست» نمایش داده می‌شود.
- منبع Live نمی‌تواند برچسب DEMO/MOCK تحویل دهد؛ خطا به‌صورت عمومی و بدون جزئیات محرمانه منتشر می‌شود.
- بازگشت موفق پس از خطا، بنر خطا را پاک می‌کند؛ ترتیب درخواست‌ها با کنترل sequence قبلی حفظ می‌شود.
- تست‌ها شبکه را شبیه‌سازی نمی‌کنند؛ با توابع خواندن ساختگی خطا/تأخیر را شبیه‌سازی می‌کنند، لذا آزمون میدانی شبکه نیستند.
- اجازه Production همچنان NO-GO است؛ Push/Merge/Deploy/Fetch/Migration ممنوع.
