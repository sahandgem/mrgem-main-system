# C53 — اعتبار اطلاعات در کابین خلبان
2026-10-12؛ فقط Core.

- تازه: تنها زمانی که همه ماژول‌های فعال تازه باشند و پوشش ناقص یا خطا نداشته باشیم.
- ناقص: نمایش مستقل و هشدار عدم کفایت برای تصمیم.
- قدیمی: نشانه جداگانه و عدم ادعای تازگی.
- خطا/نامعتبر: نشان وضعیت بحرانی.
- بدون داده/نامشخص/هیچ ماژول: «اعتبار نامشخص»، نه تازه و معتبر.
- خطای دریافت پس از یک موفقیت: «نمای قبلی؛ جاری نیست» بالاترین اولویت را دارد.
- وضعیت کسب‌وکار و سلامت داده مستقل‌اند؛ صرفاً وجود هشدار کسب‌وکاری به معنی خطای داده نیست.
- فقط تست ساختگی و واحد، بدون اتصال، مجوز عملیاتی یا انتشار.
