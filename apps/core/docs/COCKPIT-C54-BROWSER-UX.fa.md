# C54 — آزمون مرورگری کابین خلبان و دسترسی‌پذیری
تاریخ 2026-10-12. فقط `apps/core` و مرورگر با پروفایل موقت روی `127.0.0.1:5176`.

## آزمون واقعی محلی
- دسکتاپ 1365×768 و 1440×800؛ تبلت 720×900 و موبایل 420×800.
- نبود سرریز افقی، نمایش Cockpit ساختگی فقط در مسیر توسعه.
- یک پنل جزئیات، بازشدن با انتخاب سطر، بسته‌شدن با Escape و بازگشت فوکوس به سطر انتخاب‌شده.
- مسیر اصلی مدیر پس از بارگذاری هیچ داشبورد آزمایشی نشان نمی‌دهد.
- کنترل خطای JS مرورگر.
- برنامه تنها از داده Mock استفاده می‌کند؛ این آزمون اتصال یا احراز هویت واقعی نیست.

## اجرا
از پوشه `apps/core`:
```
npm.cmd exec vite -- --host 127.0.0.1 --port 5176 --strictPort
node.exe tests/c54-browser/smoke.mjs http://127.0.0.1:5176/
```
ورود مدیر همچنان بسته و تأیید Production: NO-GO. هیچ Fetch/Merge/Push/Deploy/دیتابیس انجام نمی‌شود.
