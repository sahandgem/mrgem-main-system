# C58 — شبیه‌سازی اتصال دو ماژول

با `MockModuleAdapter` موجود و `CommandCenterLiveDataSource` تزریق‌شده در تست آفلاین، شش ترکیب بررسی شد: دو منبع سالم، نیروی انسانی ناقص و تولید قدیمی، قطع نیروی انسانی و تولید سالم، payload نامعتبر/بی‌داده، شناسه تکراری، و دروازه Live بسته.

هیچ قراردادی در `packages/module-contracts` و هیچ پروژه Workforce یا Production تغییر نمی‌کند. `LIVE/READ-ONLY` صرفاً برچسب تست منبع صریحاً تزریق‌شده است و به معنی اتصال واقعی نیست. ممنوعیت Production و تغییرات عملیاتی ادامه دارد.
