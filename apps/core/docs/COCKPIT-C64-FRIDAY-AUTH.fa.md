# C64 — امنیت اتصال جمعه‌بازار
- پذیرش توکن فقط در طول ۲۰ تا ۸۱۹۲ نویسه، بدون فاصله و کنترل اعتبار محدود نشست (۲۰ دقیقه).
- پیام ورود فقط از origin و پنجره بازشده پذیرفته می‌شود؛ نشست خروج مدیر نسل قبلی درخواست را بی‌اثر می‌کند.
- رد تأیید یا خطای شبکه، پاسخ ناموفق و پاکسازی listener و پنجره؛ هیچ داده واقعی خوانده نشد.
- کنترل مجوز سمت سرور هنوز مستقل و الزامی است.
