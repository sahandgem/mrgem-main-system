# C65 — کنترل پاسخ HTTP
- GET فقط‌خواندنی، محدودیت پاسخ ۵۱۲ کیلوبایت، Content-Type JSON و timeout ده‌ثانیه‌ای.
- تعویض/ابطال توکن حتی در خلال انتظار پاسخ، داده را غیرمجاز می‌کند.
- پیام‌های شکست عمومی هستند؛ متن خام سرور و اطلاعات حساس نمایش داده نمی‌شوند.
- تست‌ها فقط با Response ساختگی انجام شدند.
