# C70 — آزمون سناریوهای بحرانی

- دو دریافت هم‌زمان و پاسخ دیررس: فقط تازه‌ترین پاسخ معتبر منتشر می‌شود.
- لغو نشست بعد از پاسخ، نمای قبلی را پاک می‌کند؛ هیچ درخواست واقعی انجام نشد.
- آزمون‌های ورود و خروج مرورگر در مرحله C71 جداگانه دوباره اجرا می‌شوند.
- این آزمون‌ها جایگزین تست نفوذ مستقل یا کنترل دسترسی سمت سرور نیستند.
