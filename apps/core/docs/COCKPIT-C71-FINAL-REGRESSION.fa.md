# C71 — گزارش آزمون جامع نسخه ترکیبی

تاریخ: 2026-10-12، فقط Worktree مستقل `Core-Merge-Trial-20261012` و داده ساختگی.

## نتایج اجرایی
- `npm.cmd run test:core`: PASS؛ آزمون‌های مرز Worktree، امنیت نشست، پاسخ HTTP، وضعیت ماژول، رفتار کابین و سناریوهای C63 تا C70.
- `npm.cmd run build:core`: PASS؛ TypeScript و Vite بدون خطا.
- Chrome C46: ۷ بررسی موفق؛ ورود/خروج ساختگی، مسیر مدیر بدون Mock، موبایل و خطاهای JS.
- Chrome C54: ۸ بررسی موفق؛ ۱۳۶۵، ۱۴۴۰، ۷۲۰ و ۴۲۰ پیکسل، پنل جزئیات، Escape و بازگشت فوکوس.
- Chrome C62: ۵ بررسی موفق؛ فعال‌شدن کنترل اتصال آزمایشی جمعه‌بازار، خواندن یک‌بار، بدون درخواست به سرویس خارجی.
- مجموع **۲۰ بررسی مرورگری موفق**؛ همه با Chrome مستقل و پروفایل موقت در 127.0.0.1:5176.

## محدودیت‌ها
صدور و لغو JWT واقعی، مجوزهای سمت سرور، RLS، سرویس اصلی حسابداری و وضعیت واقعی Production آزموده نشدند. موفقیت آزمون ساختگی به معنای اجازه ادغام اصلی، Push، Deploy یا اتصال سرویس نیست. نسخه تنها برای بازبینی محلی مناسب است.
