# Phase 6 — گیت نهایی اتصال جمعه‌بازار به Core

## هدف

Core نباید صرف دریافت access token را معادل اتصال سالم بداند.
اتصال فقط وقتی موفق محسوب می‌شود که همان توکن بتواند از مسیر HTTP adapter
یک پاسخ واقعی و موفق از Bridge جمعه‌بازار دریافت کند.

## رفتار نهایی

- popup حسابداری access token کوتاه‌عمر را به origin دقیق Core می‌فرستد.
- Core توکن را هنوز فقط در حافظه صفحه نگه می‌دارد.
- قبل از نمایش «حسابداری متصل»، Core یک read واقعی از Bridge انجام می‌دهد.
- اگر Bridge، Auth، CORS یا Source خطا بدهد، اتصال پذیرفته نمی‌شود.
- در شکست اتصال، داده جمعه‌بازار وارد Cockpit نمی‌شود و پیام خطای فارسی نمایش داده می‌شود.
- بعد از موفقیت self-test، همان Integration Backbone معمول validate/aggregate/render را انجام می‌دهد.

## محدودیت اختیار

- هیچ write API اضافه نشده است.
- Core هیچ دسترسی مستقیم به دیتابیس حسابداری ندارد.
- Service Role یا refresh token وارد Core نمی‌شود.
- هیچ پرداخت، تسویه، انتقال پول یا تصمیم مدیریتی خودکار نمی‌شود.

## گیت پذیرش

1. بدون توکن هیچ درخواست Bridge پذیرفته نشود.
2. پاسخ غیرموفق یا JSON خراب، اتصال را رد کند.
3. فقط read موفق، وضعیت متصل را فعال کند.
4. workspace boundary همچنان شبکه را فقط داخل HttpModuleAdapter مجاز بداند.
5. test:core و build:core پاس شوند.
